# Code Explainer

一个vscode插件。选中代码，一键获取逐行中文解释。鼠标悬停查看，不用再反复问 AI。

## 为什么会有这个工具？

学代码时常见的问题：

**反复追问太麻烦** — 一行不懂问一句，问几轮上下文就太长，对话框拖来拖去。

**一次问完又对不上** — 把整段代码扔给 AI 让它全部解释，结果得自己一行行去对照 AI 说了什么，比写代码还累。

Code Explainer 的做法：一次性解释整个文件，每一行的解释**直接悬浮在该行代码上**，看一眼就知道这行在干什么。

## 安装

1. 下载 `.vsix` 文件
2. VS Code → 扩展 → `...` → 从 VSIX 安装
3. 打开任意代码文件 → 点右上角 **"解释当前代码"**

首次使用会弹出输入框，填入你的 DeepSeek API Key（在 https://platform.deepseek.com 获取），一次配置，永久生效。

## 使用

- **触发**：编辑器右上角按钮 / 右键菜单 / `Ctrl+Shift+E`
- **查看**：鼠标悬停到任意代码行上
- **开关**：底部状态栏点击切换

## 隐私

API Key 保存在 VS Code 全局设置中，代码里不硬编码，开源安全。
